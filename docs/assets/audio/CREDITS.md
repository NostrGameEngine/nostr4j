# Audio credits — Sats Seas

All audio is **CC0 1.0 (public domain)**, sourced from
[OpenGameArt.org](https://opengameart.org). No attribution required;
we credit the authors anyway.

## Music

- `pirate-loop.ogg` — "Video Game Pirate" by **iamoneabe**
  (https://opengameart.org/content/video-game-pirate),
  converted from the original MP3 to OGG Vorbis (q4) to slim it down.
  A techy chiptune waltz — perfect for an 8-bit pirate game.

## Sound effects

From the **"80 CC0 RPG SFX"** pack by **SubspaceAudio**
(https://opengameart.org/content/80-cc0-rpg-sfx), renamed to the
in-game event:

| File          | Original file        | Used for              |
|---------------|----------------------|-----------------------|
| `cannon.ogg`  | `spell_fire_02.ogg`  | cannon fire           |
| `coin.ogg`    | `item_coins_01.ogg`  | picking up coin sats  |
| `hitmetal.ogg`| `metal_02.ogg`       | cannonball hits a ship|
| `hurt.ogg`    | `creature_hurt_01.ogg`| player takes damage  |
| `roar.ogg`    | `creature_roar_01.ogg`| megalodon nearby/dies |
| `npc-died.ogg`| `creature_die_01.ogg`| enemy destroyed       |
| `gem.ogg`     | `item_gem_01.ogg`    | burying treasure      |
| `click.ogg`   | `item_misc_01.ogg`   | UI clicks             |

The water **splash** is synthesized at runtime with the Web Audio API
(filtered noise burst) — no file needed.
