Try these examples in your browser, then open the source to see how they work:

| Task | Run | Java source |
|---|---|---|
| Create a temporary identity, sign and publish a note, receive it through a filter | [Run publish](../demos.md#publish) | [QuickStartDemo.java](https://github.com/NostrGameEngine/nostr4j/blob/gh-pages/site-demos/src/main/java/org/ngengine/site/demos/quickstart/QuickStartDemo.java) |
| Fetch public notes from a relay | [Run fetch](../demos.md#relay) | [RelayFetchDemo.java](https://github.com/NostrGameEngine/nostr4j/blob/gh-pages/site-demos/src/main/java/org/ngengine/site/demos/relay/RelayFetchDemo.java) |
| Query a Nostr Wallet Connect wallet | [Run wallet](../demos.md#wallet) | [NWCDemo.java](https://github.com/NostrGameEngine/nostr4j/blob/gh-pages/site-demos/src/main/java/org/ngengine/site/demos/nwc/NWCDemo.java) |
| Join a room and exchange messages | [Run RTC ping](../demos.md#rtc) | [RTCPingDemo.java](https://github.com/NostrGameEngine/nostr4j/blob/gh-pages/site-demos/src/main/java/org/ngengine/site/demos/rtc/RTCPingDemo.java) |
| Use multiple peers and routed RTC | [Run P2P Seas Game](../demos.md#game) | [P2pSeasGame.java](https://github.com/NostrGameEngine/nostr4j/blob/gh-pages/site-demos/src/main/java/org/ngengine/site/demos/game/P2pSeasGame.java) |
